## 2025-05-18 - Replacing Placeholder Components with Native Accessible React Native Elements
**Learning:** When porting web React applications to React Native Expo, interactive forms often retain static text placeholders (such as `<ThemedText>input</ThemedText>`). Converting these to native `TextInput` and `TouchableOpacity` elements with `Ionicons` greatly improves usability, provided accessible attributes (`accessibilityLabel`, `accessibilityRole="button"`), proper touch targets (44x44 minimum), theme colors (`useThemeColor`), and keyboard submit handlers (`onSubmitEditing`) are applied.
**Action:** Always check form input components in ports for leftover text placeholders and replace them with fully accessible React Native interactive controls that support both touch and keyboard interactions.
