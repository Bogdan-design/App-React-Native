## 2025-05-18 - React Native AddItemForm Micro-UX and Accessibility
**Learning:** Replacing static text placeholders in ported components with native `TextInput` controls and accessible icon buttons drastically improves keyboard usability, visual feedback, and screen reader navigation.
**Action:** Always provide explicit `accessibilityLabel`, `accessibilityRole="button"`, and theme-aware colors when building or replacing form controls in React Native components.
