## 2025-05-18 - Accessibility Attributes in React Native Web & Expo Router Routing
**Learning:** In React Native Web, combining `aria-label` and `role` with `accessibilityLabel` and `accessibilityRole` ensures cross-platform accessibility and avoids React Native Web deprecation warnings.
**Action:** Include both web-standard ARIA props (`aria-label`, `role`) and React Native props (`accessibilityLabel`, `accessibilityRole`) on interactive components.
