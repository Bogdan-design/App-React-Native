## 2025-05-18 - Replacing Placeholder Form Text with Accessible Native Controls
**Learning:** Legacy web-migrated components in React Native Expo projects may contain placeholder `<ThemedText>` elements (e.g. `<ThemedText>input</ThemedText>`) or DOM-bound event handlers (`onChange` with `HTMLInputElement`). Replacing these with React Native `TextInput` (`onChangeText`, `onSubmitEditing`, `editable`) and accessible icon buttons (`accessibilityLabel`, `accessibilityRole="button"`, `minWidth: 44, minHeight: 44`) restores expected mobile UX and keyboard/screen reader functionality.
**Action:** When updating form inputs, use `TextInput` with `onSubmitEditing`, apply `accessibilityLabel` and `accessibilityRole="button"` to icon-only pressable controls, and ensure touch targets adhere to at least 44x44 points.
